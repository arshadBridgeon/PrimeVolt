## What this is

"Prime Volt" (launcher name; formerly QT Generator), a Flutter app that makes, stores and shares PDF quotations and project files for one business (PRIME VOLT TECHNOLOGY, a solar/CCTV installer in Kondotty, Kerala). Amounts are ₹ with Indian grouping (`2,36,000`). Only `android/` and `web/` platform folders exist, and the target is Android. Sharing uses `dart:io`, so it won't work on web.

## Commands

```bash
flutter pub get
flutter run -d <device-id>      # `flutter devices` to list; usually a USB Samsung phone
flutter analyze                 # flutter_lints
flutter test                    # test/utils_test.dart
flutter test test/utils_test.dart --plain-name "amountInWords uses lakh/crore"
flutter build apk --release     # release is signed with debug keys (android/app/build.gradle.kts)
dart run flutter_launcher_icons # regenerate launcher icons from assets/app_icon.png
```

## Architecture

- **State**: `AppState` ([lib/app_state.dart](lib/app_state.dart)) is a plain `ChangeNotifier` created in the app root and passed through constructors. Every page wraps itself in `ListenableBuilder(listenable: appState)`. MaterialApp is not rebuilt on changes, so pushed routes must listen themselves. `provider` is in pubspec but not used.
- **Firebase** (project `primevolt-faa42`, config in `lib/firebase_options.dart` + `android/app/google-services.json`, generated by `dart pub global run flutterfire_cli:flutterfire configure`): email/password Auth gates the app ([lib/pages/login_page.dart](lib/pages/login_page.dart)); there is no sign-up, accounts are added in the Firebase console. All signed-in users share one dataset in Firestore: `quotations/{id}`, `projects/{id}`, `settings/company`, `users/{uid}` (display name). After sign-in the app requires a name ([lib/pages/name_page.dart](lib/pages/name_page.dart)); new quotations/projects store `createdByUid`/`createdByName`, and cards show the creator via `AppState.creatorName` (live name from `users`, so renames propagate). [firestore.rules](firestore.rules) allows any signed-in user; deploy with `firebase deploy --only firestore:rules --project primevolt-faa42`.
- **Persistence**: `AppState` listens to Firestore snapshots and writes fire-and-forget (local cache updates instantly, syncs when online), so never `await` a write against the server in UI code. Models ([lib/models.dart](lib/models.dart)) use hand-written JSON with defaults in `fromJson`, so new fields need a fallback there to keep old docs loading. Pre-Firebase data in SharedPreferences is uploaded once on first sign-in per phone (`migrated_to_firestore` flag). **Images are not in Firebase** (no Storage on the free plan): project photo paths and the signature path point at files on the phone that added them; the signature path is kept in SharedPreferences, not Firestore, and PDFs skip missing photo files.
- **Defaults**: [lib/defaults.dart](lib/defaults.dart) holds the standard 18 solar items, notes and terms copied from the company's myBillBook quotation. `AppState.newQuotation()` pre-fills every new quotation with them, and the user then edits per quotation. Quote numbers continue from `0259`.
- **Totals** (getters on `Quotation`): subtotal → minus `discount` (flat) → plus `tax` (a **percentage** of the discounted amount) → plus `additional` → plus `roundOff`. The business usually leaves item rates at 0 and puts the lump-sum price in Round Off. The editor's "Set total amount" button computes that.
- **PDF** ([lib/pdf_service.dart](lib/pdf_service.dart)): `PdfKit` holds the shared fonts, logo, header (company name bold italic), grey band and signatory. The quotation PDF is a `pw.MultiPage` copying the myBillBook layout, with a fixed logo from `assets/company_logo.png`, a thick rule, a grey number/date band, BILL TO, an item table (ITEMS + QTY only, no prices) whose header row has `repeat: true`, a subtotal row, notes and terms on the left with totals, amount in words (`amountInWords`, lakh/crore) and the signatory on the right.
- **Project files**: `ProjectFile` (models.dart), stored in the `projects` collection. Photos are copied into `<app docs>/project_photos`; `AppState.saveProject` deletes photo files an edit removed, and the editor deletes photos added in a discarded session. [lib/project_pdf.dart](lib/project_pdf.dart) reuses `PdfKit` and adds a "PROJECT FILE" heading, key-value sections, a 2x2 status grid, serial numbers and a 2-column photo grid. A project can be created from a quotation (copies the customer and total).
- **PDF fonts**: Roboto plus Noto Color Emoji as `fontFallback`, loaded through `PdfGoogleFonts`. They download on first use and are then cached, which is why the main manifest has the INTERNET permission. The built-in Helvetica has no ₹ glyph. If the font load fails (offline on first use), the PDF uses "Rs." and strips emoji.
- **Expenses**: `Expense` docs in `expenses/{id}`; categories are a shared editable list in `settings/expense_categories` (`AppState.expenseCategoryList`, defaults in models.dart). [lib/expense_pdf.dart](lib/expense_pdf.dart) builds the period report (table + category summary) shown from the Expenses tab.
- **UI** ([lib/pages/](lib/pages/)): 5 tabs in a floating frosted [GlassNavBar](lib/glass_nav_bar.dart) (Home, Quotations, Projects, Expenses, Profile = settings_page.dart). The root Scaffold uses `extendBody`, so tab pages must add `navBarClearance(context)` to bottom list padding and FAB offsets. Customers (derived from quotations, not stored) opens from a Dashboard button. Shared flows (open preview or editor, duplicate, status, delete) are in `quotation_actions.dart`. Brand colours and the theme are in [lib/theme.dart](lib/theme.dart), and reusable cards and chips are in [lib/widgets.dart](lib/widgets.dart).
